# Fictional equipment glossary

The demonstration rig is an invented software fixture used to generate landing-gear-style cycle summaries. It does not represent an actual aircraft, supplier, or test installation.

Pressure, extension time, vibration, temperature, and cycle duration are synthetic display fields. Their units and values were chosen for a readable software example and do not describe real equipment.
